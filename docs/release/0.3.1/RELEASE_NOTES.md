# VoiceBar v0.3.1

- **设置界面更清爽。** 改为「深色侧栏 + 居中内容」布局。品牌名和页面标题各只出现一次，去掉了单独的标题栏、面包屑和英文小标题；最小化、最大化、关闭按钮并入内容区右上角。侧栏导航改为单行。
- **新的深灰配色。** 设置窗口与托盘菜单统一换色，薄荷绿只用于需要强调的地方。内容最宽 820px 并居中，窗口变窄时边距随之收小。
- **选项更好点。** 帧率、写入方式等改为分段选择器；识别服务改为左右对齐的两列单选卡；麦克风选中状态与开关行样式统一。
- **浮框轮廓更清楚。** 结构与尺寸不变，边框改为半透明白色细线，深色和浅色桌面上都能看清。

本版本只调整界面，识别、写入和配置格式与 v0.3.0 相同，升级后原有设置保持不变。

## 下载

Windows 10/11 x64 安装包为 `VoiceBar_0.3.1_x64-setup.exe`。免安装版为 `VoiceBar_0.3.1_x64-portable.zip`。手动升级时先从托盘退出正在运行的旧版。

## 验证范围

Windows 本地通过 95 项 Rust 测试。原生 GPUI 测试在独立窗口中渲染了四个设置页（宽、窄两种窗口），检查了 65%、100%、180% 三种缩放下浮框所有元素不越界，并截取了托盘菜单。此次未用真实麦克风重新检查录音中和出错时的界面。
