# VoiceBar v0.3.0

- **短句可以按住说。** 在「输入与启动」开启「按住说话」并保存，按住快捷键录音，松开后结束。流式引擎可在浮框预览，文字在松键后统一写入。选择「仅预览」时可手动复制。已有用户仍可按一下开始，再按一下结束。
- **配引擎之前先试麦。** 在「输入与启动」刷新设备，选好麦克风即可查看实时电平。测试六秒后自动结束，也可以手动停止。音频仅在本机测量。
- **找回上一句。** 在「工作台」开启「最近识别」并保存，可从内存里复制最近 5 条听写的全文。识别中断时，已收到的文字会单独标明。默认关闭，可随时清空，退出即释放。
- **分清服务与设备问题。** 工作台分别提供识别服务配置和实际听写试用入口。识别设置会根据当前协议显示热词输入或支持情况。
- 取消听写可中止后续字符写入。正在收尾或校对时取消，该次听写也会从最近识别中排除。

## 下载

Windows 10/11 x64 安装包为 `VoiceBar_0.3.0_x64-setup.exe`。免安装版为 `VoiceBar_0.3.0_x64-portable.zip`。手动升级时先从托盘退出正在运行的旧版。

## 验证范围

Windows 本地通过 95 项 Rust 测试和 11 项发布清单测试。另用默认麦克风和独立 GPUI 窗口验证了本机试麦、按住 F22 后松键结束、持续持键到达录音时限，以及连续两段文字的取回。在独立 Win32 编辑框验证了分步松键、焦点切换和取消长文本写入。

识别内容来自本机 FunASR 协议测试服务；此次未测量付费云端识别的准确率或延迟。[同类项目对照与功能取舍](https://github.com/MLGBJDLW/VoiceBar/blob/v0.3.0/docs/open-source-comparison-2026-11-06.md)
