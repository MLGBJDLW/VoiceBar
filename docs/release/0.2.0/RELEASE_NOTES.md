# VoiceBar v0.2.0

Windows 原生 GPUI 版本。设置页、语音条与托盘统一采用深灰和薄荷色，支持直接按键录入快捷键。

## 新增

- 「边说边写」根据流式中间结果修订本次输入尾部；切换输入位置或手动编辑后暂停自动写入。新配置默认使用此模式，已有配置保留原选择。
- 停顿自动结束：说话后安静 1–30 秒可自动收尾，默认关闭。
- 独立静默启动设置；手动启动与开机自启的窗口行为可分别控制。
- 十秒桌面位置预览，以及录音期间可独立保存的外观与位置。

## 改进与修复

- 设置页和语音条从 Tauri / WebView2 / TypeScript 迁为 Rust / GPUI；重整工作台、外观、识别引擎和输入设置，加入自绘窗口栏，运行时无需 WebView2 或 Node.js。
- 托盘菜单与设置页共享深灰/薄荷色及字体，覆盖选中、禁用、快捷键和分隔线；保留 Windows 原生键盘导航，高对比度模式使用系统配色。
- 将快捷键按键录入迁至原生控件，提供单项/全部恢复默认及取消键禁用；保存后生效，占用时保留原绑定。
- 声音响应改为 Rust 频谱与响度分析，共用设置预览与语音条绘制；改善停顿收拢、继续说话展开及减少动态模式。
- 修复语音条长文字/状态提示导致按钮越界和缩放布局不同步，以及原生托盘消息处理与当前用户自启注册表句柄问题。
- 修复 Windows Manifest 重复资源引起的 MSVC 链接失败；打包时使用 Windows SDK 校验并写入完整应用清单。

七种识别协议、九宫格与四种动效、可选结束校对、自启、DPAPI 密钥加密和签名更新在上一版已有，本版保留或迁移这些能力。原有三种写入模式仍可选择。

## 下载与升级

- 安装版：`VoiceBar_0.2.0_x64-setup.exe`，按当前 Windows 用户安装。
- 便携版：`VoiceBar_0.2.0_x64-portable.zip`，解压后运行 `VoiceBar.exe`。
- Windows 10 / 11 x64，需要正常工作的图形驱动。
- 升级前从托盘退出旧实例，再启动新版；运行中的旧窗口不会自动替换。
- 识别服务需要配置自己的本机服务或云端账户；不内置识别模型，不默认保存录音与历史。
- 原生版目前仅实现 `--hidden`；旧版 `--toggle` / `--cancel` 尚未迁移，请使用全局快捷键或托盘控制录音。
- 本版不再生成 MSI，保留 NSIS 安装包和便携 ZIP。
- 默认启动检查更新会访问 GitHub；「仅手动」和「从不」可在设置中选择。默认不保存录音和识别历史不代表完全离线。
- 本地 GNU 回归 83 项、托盘原生菜单夹具 1 项、发布清单测试 11 项通过。真实麦克风、各云识别服务、安装/卸载和旧版升级未在本轮实测。
- 验证记录见 [托盘主题验证](https://github.com/MLGBJDLW/VoiceBar/blob/v0.2.0/docs/tray-theme-verification.md)；[逐项 Changelog 核对](https://github.com/MLGBJDLW/VoiceBar/blob/v0.2.0/docs/release/0.2.0/CHANGELOG_AUDIT.md) 区分了本版新增与旧版已有能力。
