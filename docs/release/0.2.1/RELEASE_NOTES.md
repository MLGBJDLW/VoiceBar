# VoiceBar v0.2.1

## 改进与修复

- **手动输入后继续听写。** 打字或移动光标后，语音条继续显示识别结果，右上角变为「继续」。选好输入位置，按原快捷键或点「继续」即可接着写，手打文字会保留。暂停期间的文字可从语音条复制。
- **停顿后继续出字。** 修复阿里云 Paraformer v2 在静音停顿后可能断流，以及空心跳清除临时文字的问题。
- **半透明浮框。** 默认背景不透明度从 94% 调至 76%，可在「外观与动效」调整。旧配置中原为 94% 的浮框会使用新默认值。

## 下载与升级

- Windows 10/11 x64 安装版为 `VoiceBar_0.2.1_x64-setup.exe`。便携版为 `VoiceBar_0.2.1_x64-portable.zip`，解压后运行 `VoiceBar.exe`。手动升级前请从托盘退出旧实例。

## 验证范围

已在 Windows 原生输入框验证快捷键和浮框按钮恢复、切换输入框，以及半透明背景。用本机模拟识别服务验证了停顿 25 秒后继续写入下一句。付费云端识别准确率未在本次验证范围内。[Windows 验证记录](https://github.com/MLGBJDLW/VoiceBar/blob/v0.2.1/docs/native-verification.md)
